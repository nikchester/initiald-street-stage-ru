# Initial D Street Stage (PSP) — русский перевод

Фанатский перевод японской игры **頭文字D STREET STAGE** (PSP, `ULJM-05093`, версия диска 1.01) на русский язык.

Репозиторий содержит только инструменты и русский текст. Файлов игры здесь нет. Нужен собственный дамп ISO.

## Состояние

- [x] Весь текст программы (`BOOT.BIN`): меню, сообщения, сохранение, гараж, сеть, советы на уроках
- [x] Пропорциональный шрифт для кириллицы (правка функции вывода текста)
- [x] Описания карточек (185 штук)
- [x] Сайт Project D: галерея, голоса, разбор трасс, видео, рекорды
- [x] Картинки меню: заголовки и подсказки всех экранов, кнопки, настройки, гараж, тюнинг, выбор трассы и соперника, сообщения в гонке, пауза, повторы, лобби
- [ ] Диалоги соперников — не переводятся (решение автора)
- [ ] Мелкие надписи на рисунках карточек, часть подписей сайта, подписи «AT/MT»

## Сборка

Нужны Python 3.12+, Pillow, а для перерисовки картинок — `opencv-python-headless` и `capstone` (только для анализа).

1. Положите ISO в корень проекта под именем `Initital_D_Street_Stage_JAP_PSP-DMU.iso`.
2. Распакуйте его: `7z x -oextracted Initital_D_Street_Stage_JAP_PSP-DMU.iso`.
3. Выгрузите картинки главного меню:
   `python tools/gim.py dump extracted/PSP_GAME/USRDIR/data/select/sel_gamemode.bin.gz work/png/sel_gamemode`.
4. Соберите образ: `python tools/build.py`.

Результат: `build/InitialD_RU.iso`. Изменённый `BOOT.BIN` подставляется вместо зашифрованного `EBOOT.BIN`, поэтому на PSP нужна кастомная прошивка.

## Как устроен перевод

| Часть | Файлы перевода | Инструмент |
|---|---|---|
| Строки `BOOT.BIN` | `text/boot_ru_*.json` (ключ — адрес строки) | `tools/boot_build.py`, `tools/bootpatch.py` |
| Карточки | `text/cards_ru_*.json` (ключ — номер карточки) | `tools/texts.py` |
| Сайт Project D | `text/hp_ru.json` | `tools/texts.py` |
| Картинки | `text/images_ru_*.json` (ключ — md5 исходной GIM) | `tools/imgtr.py` |
| Шрифты | — | `tools/fonts.py` |

## Форматы игры

| Формат | Описание |
|---|---|
| `XBB` | Архив: заголовок 0x20, записи `{offset, size, name_offset, hash}`, таблица хешей, имена, данные с выравниванием 0x80. Часто сжат gzip. |
| `@ANA` | Контейнер картинок: записи `{offset, size, name[8]}`, внутри GIM. |
| `GIM` | Текстура PSP. Форматы RGBA и индексные 4/8 бит, swizzle. |
| `lba.dat` | Индекс файлов. Игра ищет файлы по хешу пути и смещению в ISO, а не через ISO9660. |
| `*_lst.txt` | Таблица символов шрифта; номер символа — его порядок в файле. Атлас 256×256, ячейки 16×16 (у шрифта имён — 22×22). |
| `BOOT.BIN` | Незашифрованный перемещаемый PRX. Строки находятся через таблицы релокаций. |

## Технические приёмы

- Длинные русские строки переносятся в новую область в конце модуля, ссылки перенаправляются по релокациям.
- Функция вывода текста (`0xb7bac`) получила таблицу ширин: кириллица и узкие символы на странице Shift-JIS `0x84`.
- Русская пунктуация, цифры и латиница кодируются частными кодами `0x84 0x92–0xFC`, чтобы японский текст не менялся.
- Объект шрифта рисует не больше 176 символов, поэтому описания карточек ограничены ~170 знаками.
- Надписи на табличках вписываются в рамку исходного текста: игра выводит их отдельным спрайтом по этой рамке.
