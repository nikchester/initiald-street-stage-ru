# Initial D Street Stage (PSP) — русский перевод

Фанатский перевод японской игры **頭文字D STREET STAGE** (PSP, `ULJM-05093`, версия диска 1.01) на русский язык.

Репозиторий содержит только инструменты. Файлов игры здесь нет. Нужен собственный дамп ISO.

## Состояние

- [x] Распаковка и сборка архивов игры
- [x] Сборка ISO с обновлением индекса `lba.dat`
- [x] Экран выбора режима (главное меню)
- [ ] Остальные экраны меню (картинки)
- [ ] Системные сообщения и текст в `BOOT.BIN`
- [ ] Диалоги соперников (`rivaldemo`)
- [ ] Карточки, сайт Project D, титры

## Сборка

Нужны Python 3.12+ и Pillow.

1. Положите ISO в корень проекта под именем `Initital_D_Street_Stage_JAP_PSP-DMU.iso`.
2. Распакуйте его: `7z x -oextracted Initital_D_Street_Stage_JAP_PSP-DMU.iso`.
3. Выгрузите картинки экрана выбора режима:
   `python tools/gim.py dump extracted/PSP_GAME/USRDIR/data/select/sel_gamemode.bin.gz work/png/sel_gamemode`.
4. Соберите образ: `python tools/build.py`.

Результат: `build/InitialD_RU.iso`.

## Форматы игры

| Формат | Описание |
|---|---|
| `XBB` | Архив: заголовок 0x20, записи `{offset, size, name_offset, hash}`, таблица хешей, имена, данные с выравниванием 0x80. Часто сжат gzip. |
| `@ANA` | Контейнер картинок: записи `{offset, size, name[8]}`, внутри GIM. |
| `GIM` | Текстура PSP. Форматы RGBA и индексные 4/8 бит, swizzle. |
| `lba.dat` | Индекс файлов. Игра ищет файлы по хешу пути и смещению в ISO, а не через ISO9660. |
| `*_lst.txt` | Таблица символов шрифта `символ=номер`, Shift-JIS. Атлас: 256×256, ячейки 16×16. |

## Инструменты

| Файл | Назначение |
|---|---|
| `tools/xbb.py` | Распаковка и упаковка `XBB` |
| `tools/isopatch.py` | Замена файлов в ISO с обновлением `lba.dat` |
| `tools/gim.py` | GIM ↔ PNG, выгрузка и вставка картинок в `@ANA` и `XBB` |
| `tools/gimfont.py` | Атласы шрифта и таблицы символов |
| `tools/art.py` | Отрисовка русских надписей в стиле игры |
| `tools/menu_gamemode.py` | Русские картинки экрана выбора режима |
| `tools/build.py` | Сборка русского ISO |
| `tools/build_font_test.py` | Тест кириллицы в диалогах |
| `tools/contact.py` | Сводный лист картинок для просмотра |
